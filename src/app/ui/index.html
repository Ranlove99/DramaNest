单条地址 / m3u8 直链

支持部分短剧站点的分集接口（自动抓全集）；也可直接粘贴任意 m3u8 或直链 mp4，AES-128 会自动解密。多个地址用换行分隔可批量下载。

整站扫描 · 批量下载

单次最多提交 300 部；已下载完成的会自动跳过。下载按设置里的并发数排队执行。

设置

状态是应用账号 dramanest 的真实读写权限。显示「只读 / 无权限」说明系统还没把这个文件夹授权给应用。

同时进行的下载任务数（1~8）。数值越大占带宽越多；大屏/高速网络可调到 3~4。

本地分段兜底时同时下载的分片数（1~16）。一集常有一两百个分片，调到 6~10 能快好几倍；源站限速时调小。

开启后资源站会多出「成人内容」分区；关闭时这些源不可浏览、不可下载。

内置源导入 / 导出

导出当前全部源为 JSON；导入可粘贴 JSON 或选择本地 .json 文件。

站点排序与文件夹分类

拖动或用箭头调整顺序；「文件夹」相同的源在资源站下拉里归到同一分组。禁用的源自动排到最后。

新增站点表单 / 直接编辑 JSON

新增站点：填好名称与接口地址，点上方「+ 新增站点」即可加入列表，再保存。

格式：[{"name":"名称","api":"接口地址","category":"normal 或 adult","folder":"分组名"}]。仅用于下载你有权访问的合法内容。
